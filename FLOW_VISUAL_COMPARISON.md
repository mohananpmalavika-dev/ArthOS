## 🎯 Key Differences at a Glance

### Navigation Structure

**Individual Flow:**
```
🏠 HOME
   ↓ Personal dashboard
   
📋 ASSESSMENT
   ↓ Fill 16-field form
   
📊 REPORTS
   ↓ PDF export
   
🧠 COGNITION
   ↓ AI insights
   
🎮 SIMULATOR
   ↓ What-if scenarios
   
🤝 PARTNERS
   ↓ Service recommendations
```

**Enterprise Flow:**
```
📊 PORTFOLIO
   ↓ Aggregate metrics & alerts
   
👥 CUSTOMERS

📋 COMPLIANCE
   ↓ Regulatory reports

   ↓ Trends & insights

   ↓ Configuration
```

## 🎨 UI/UX Differences

### Individual App
- **Focus**: Personal journey
- **Tone**: Empowering, supportive
- **Colors**: Purple (primary), Cyan (accent)
- **Interactions**: Form submission, PDF export, scenario simulation
- **Users**: 1 (you)

### Enterprise Portal
- **Focus**: Portfolio oversight
- **Tone**: Data-driven, compliance-focused
- **Colors**: Cyan (primary), Green (good), Red (alert)
- **Interactions**: Search, filter, drill-down, bulk export
- **Users**: Multiple (roles: admin, analyst, viewer)

## 🚀 Implementation Paths

### Path 1: Consumer App Only
```bash
npm run dev  # Default = Individual flow
```

### Path 2: Enterprise Portal Only
```bash
VITE_APP_MODE=enterprise npm run dev  # Enterprise flow only
```

### Path 3: Dual Mode (Both)
```jsx
// Route based on subdomain/domain
if (subdomain === 'enterprise') {
  return <EnterpriseBankPortal />;
}
return <App />;  // Individual
```
